# 자주 묻는 질문 (FAQ)

---

## 비용 관련

### Q. 정말 무료로 사용할 수 있나요?

**서버 비용은 무료입니다.** Oracle Cloud Free Tier는 평생 무료이며, 무료 범위 내에서는 과금되지 않습니다. 단, AI 글 생성에 사용하는 Gemini API는 무료 한도를 초과하면 소액의 비용이 발생할 수 있습니다.

| 항목 | 비용 |
|------|------|
| Oracle Cloud 서버 | 무료 (평생) |
| Gemini 글 생성 API | 무료 (일 1,500회까지) |
| Gemini 이미지 생성 API | 무료 (분당 2~5회) |
| 구글 시트 | 무료 |
| 워드프레스 | 무료 (셀프호스팅) |

일반적인 개인 블로그 운영(하루 5~10개 글)에서는 무료 한도를 초과할 일이 거의 없습니다.

### Q. Oracle Cloud 가입할 때 신용카드를 등록하는데, 돈이 빠져나가지 않나요?

가입 시 카드 인증을 위해 소액(약 100원)이 결제되었다가 자동으로 취소됩니다. 이후 무료 티어(Always Free) 범위 내에서만 사용하면 과금되지 않습니다. Oracle Cloud는 무료 계정에서 유료 서비스로 자동 전환되지 않으며, 본인이 직접 "Upgrade" 버튼을 누르지 않는 한 과금되지 않습니다.

### Q. 무료 한도를 초과하면 어떻게 되나요?

Gemini API 무료 한도를 초과하면 해당 시간/일의 요청이 거부됩니다 (자동 과금되지 않음). 다음 날 또는 다음 분에 한도가 초기화되면 다시 사용할 수 있습니다. 유료로 전환하려면 별도로 결제 설정을 해야 하므로, 모르는 사이에 비용이 나갈 걱정은 없습니다.

## 설치 관련

### Q. 컴퓨터를 꺼도 계속 작동하나요?

네. 프로그램은 Oracle Cloud 서버에서 돌아가기 때문에 내 컴퓨터와 무관하게 24시간 작동합니다. 구글 시트에 키워드를 입력하면 서버가 자동으로 처리합니다.

### Q. Windows/Mac 어떤 것을 사용해도 되나요?

네. 설치 과정에서 서버에 접속할 때만 컴퓨터를 사용하고, 이후에는 웹 브라우저(구글 시트, n8n)만으로 모든 작업이 가능합니다. 스마트폰에서도 구글 시트에 키워드를 입력할 수 있습니다.

### Q. 서버 세팅이 어려워요. 대신 해주실 수 있나요?

프리미엄 패키지를 구매하시면 1:1로 서버 세팅을 도와드립니다. 크몽에서 "프리미엄 세팅 서비스" 상품을 확인해주세요.

### Q. 기존에 사용하던 워드프레스 블로그에도 연결할 수 있나요?

네. 기존 워드프레스 블로그의 관리자 페이지에서 Application Password만 발급받으면 바로 연결할 수 있습니다. 매뉴얼 STEP 8을 참고해주세요.

### Q. 티스토리 블로그에도 사용할 수 있나요?

현재 버전은 워드프레스를 지원합니다. 티스토리 연동은 추후 업데이트 예정입니다. 단, 구글 시트에 글을 생성하는 기능은 블로그 종류와 무관하게 사용 가능합니다. 생성된 글을 복사해서 티스토리에 직접 올리실 수 있습니다.

### Q. 네이버 블로그에 자동으로 올릴 수 있나요?

네이버 블로그는 공식적으로 외부 포스팅 API를 제공하지 않아 자동 포스팅이 불가합니다. 글감 자동 생성 기능을 이용해서 구글 시트에 글을 만든 후, 네이버 블로그에 직접 복사-붙여넣기 하시는 방법을 추천드립니다.

## 사용 관련

### Q. 한 번에 몇 개의 글까지 생성할 수 있나요?

한 번에 여러 키워드를 입력할 수 있습니다. 단, Gemini API 무료 한도(분당 2~5회)에 따라 한 번에 너무 많이 입력하면 순차적으로 처리됩니다. 한 번에 10~20개 정도 입력하는 것을 추천드립니다.

### Q. 생성된 글의 품질은 어느 정도인가요?

Gemini AI가 작성한 초안입니다. SEO 최적화 구조(제목, 소제목, 키워드 밀도)는 자동으로 맞춰지지만, 최상의 결과를 위해서는 생성된 글을 한 번 검토하고 수정하시는 것을 추천드립니다. 특히 전문적인 내용(의학, 법률 등)은 반드시 사실 확인이 필요합니다.

### Q. 프롬프트를 직접 바꿀 수 있나요?

네. 두 가지 방법이 있습니다:

1. **구글 시트에서 개별 변경**: "프롬프트(선택)" 컬럼에 원하는 프롬프트를 직접 입력하면 해당 글에만 적용됩니다.
2. **기본 프롬프트 변경**: n8n 워크플로우의 "Gemini API 호출" 노드에서 기본 프롬프트를 수정할 수 있습니다.

### Q. 이미지 스타일은 어떤 것을 선택해야 하나요?

| 스타일 | 설명 | 추천 |
|--------|------|------|
| 일러스트 | 깔끔한 디지털 아트 | 정보성 글, 가이드, 리뷰 |
| 사진풍 | 실제 사진 같은 이미지 | 여행, 음식, 라이프스타일 |
| 미니멀 | 심플한 디자인 | IT, 비즈니스, 자기계발 |

잘 모르겠으면 "일러스트"를 선택하세요. 가장 범용적으로 잘 어울립니다.

### Q. 자동 포스팅하면 바로 공개되나요?

아닙니다. 자동 포스팅 시 **"초안(Draft)"** 상태로 올라갑니다. 워드프레스 관리자 페이지에서 확인하고 "공개" 버튼을 직접 눌러야 실제로 공개됩니다. 검토 없이 바로 공개되는 것은 아니니 안심하세요.

### Q. 글 생성에 시간이 얼마나 걸리나요?

- **글만 생성** (이미지 없음): 약 1~3분
- **글 + 이미지 생성**: 약 3~5분
- **글 + 이미지 + 워드프레스 포스팅**: 약 5~8분

구글 시트 트리거가 5분 간격으로 확인하므로, 키워드 입력 후 최대 5분 정도 대기 시간이 추가될 수 있습니다.

## 트러블슈팅

### Q. "상태"가 "대기"에서 바뀌지 않아요.

1. n8n에 접속하여 워크플로우가 **Active** 상태인지 확인하세요.
2. 구글 시트와 n8n의 Google Sheets 연결이 정상인지 확인하세요.
3. n8n 워크플로우의 "Executions" 탭에서 에러 메시지를 확인하세요.

### Q. "에러" 상태가 되었어요.

구글 시트 상태 컬럼이 "에러"가 되었거나, n8n Executions에서 빨간색 실패 표시가 보이면:

1. n8n에서 해당 실행 기록을 클릭합니다.
2. 어떤 노드에서 에러가 발생했는지 확인합니다.
3. 일반적인 원인:
   - **Gemini API 호출 실패**: API 키가 잘못되었거나, 무료 한도 초과
   - **Google Sheets 연결 실패**: 구글 인증이 만료됨 → n8n에서 재인증
   - **WordPress 포스팅 실패**: 워드프레스 주소 또는 비밀번호 오류

### Q. 서버(Oracle Cloud)가 갑자기 멈췄어요.

Oracle Cloud Free Tier는 장기간 사용하지 않으면(유휴 상태) 서버를 회수할 수 있습니다. 우리 프로그램은 24시간 자동으로 돌아가므로 일반적으로 이 문제가 발생하지 않지만, 만약 발생한다면:

1. Oracle Cloud 콘솔에 로그인합니다.
2. Compute → Instances에서 인스턴스 상태를 확인합니다.
3. "Stopped" 상태라면 "Start" 버튼을 클릭합니다.
4. SSH로 접속 후 `cd blog-automation/infrastructure && docker compose up -d` 를 실행합니다.

### Q. n8n 비밀번호를 잊어버렸어요.

서버에 SSH로 접속한 후:
```
cd blog-automation/infrastructure
nano .env
```
`N8N_PASSWORD` 값을 새 비밀번호로 변경하고 저장한 후:
```
docker compose restart n8n
```

### Q. 프로그램을 업데이트하고 싶어요.

업데이트가 있을 경우 크몽을 통해 안내드립니다. 일반적으로 새로운 워크플로우 JSON 파일을 받아서 n8n에 다시 import하면 됩니다. 기존 설정(API 키, 구글 시트 연결 등)은 유지됩니다.

## 기타

### Q. 생성된 글의 저작권은 누구에게 있나요?

AI가 생성한 글의 저작권은 생성을 요청한 사용자(구매자)에게 있습니다. 자유롭게 수정, 공개, 상업적 활용이 가능합니다.

### Q. 여러 블로그에 동시에 사용할 수 있나요?

네. n8n에서 워크플로우를 복제하고 각각 다른 워드프레스 블로그를 연결하면 됩니다. 구글 시트도 블로그별로 분리하는 것을 추천합니다.

### Q. 모바일(스마트폰)에서도 사용할 수 있나요?

구글 시트 앱에서 키워드를 입력하면 됩니다. n8n 관리 페이지도 모바일 브라우저에서 접속 가능하지만, 초기 설정은 PC에서 하시는 것을 추천합니다.

### Q. 환불 규정은 어떻게 되나요?

크몽 플랫폼의 환불 규정을 따릅니다. 디지털 상품 특성상 파일 다운로드 후에는 환불이 제한될 수 있으며, 상세 내용은 크몽 고객센터를 참고해주세요.
