# Apps Script 테스트 가이드 (개발자용)

> 이 가이드는 apps-script/src/ 코드를 실제 Google Sheets에 복사하고 테스트하는 과정입니다.

---

## PART 1: Google Sheets 준비

### 1-1. 새 시트 만들기

1. https://sheets.google.com 접속
2. **"빈 스프레드시트"** 클릭
3. 시트 이름을 **"블로그 자동화 도구"**로 변경

### 1-2. 탭 3개 만들기

기본 "Sheet1" 탭 외에 2개를 추가하고, 이름을 변경합니다.

| 순서 | 탭 이름 | 방법 |
|------|---------|------|
| 1 | `설정` | Sheet1 탭 이름을 더블클릭 → `설정`으로 변경 |
| 2 | `글감 생성` | 하단 + 버튼으로 새 탭 추가 → `글감 생성`으로 변경 |
| 3 | `프롬프트 설정` | 하단 + 버튼으로 새 탭 추가 → `프롬프트 설정`으로 변경 |

### 1-3. "설정" 탭 구성

`설정` 탭에 아래 내용 입력:

| | A열 | B열 |
|---|-----|-----|
| 1행 | `Gemini API 키` | (나중에 입력) |
| 2행 | `WordPress 주소` | (나중에 입력, 선택) |
| 3행 | `WordPress 아이디` | (나중에 입력, 선택) |
| 4행 | `WordPress App Password` | (나중에 입력, 선택) |

### 1-4. "글감 생성" 탭 구성

`글감 생성` 탭의 **1행(헤더)**에 아래 입력:

| A1 | B1 | C1 | D1 | E1 | F1 | G1 | H1 |
|----|----|----|----|----|----|----|-----|
| `키워드` | `이미지생성` | `이미지스타일` | `자동포스팅` | `상태` | `생성된 제목` | `생성된 본문` | `포스팅 결과` |

**드롭다운 설정 (선택사항이지만 추천):**

- B열 (이미지생성): 데이터 → 데이터 확인 → 드롭다운 → `Y`, `없음`
- C열 (이미지스타일): 드롭다운 → `일러스트`, `사진풍`, `미니멀`
- D열 (자동포스팅): 드롭다운 → `Y`, `N`

### 1-5. "프롬프트 설정" 탭 구성

`프롬프트 설정` 탭에 아래 입력:

| | A열 | B열 |
|---|-----|-----|
| 1행 | `글 톤` | `친근한` |
| 2행 | `글 길이` | `2000자` |
| 3행 | `커스텀 프롬프트` | (비워둠) |

## PART 2: Apps Script 코드 복사

### 2-1. Apps Script 편집기 열기

1. 시트 상단 메뉴: **확장 프로그램** → **Apps Script**
2. 새 탭에서 Apps Script 편집기가 열립니다

### 2-2. 기본 파일 이름 변경

편집기에 `코드.gs` (또는 `Code.gs`)가 기본으로 있습니다.
1. `코드.gs` 파일 이름 옆의 **⋮** 클릭 → **이름 바꾸기**
2. `Config`로 변경 (확장자 .gs는 자동)

### 2-3. 파일 생성 및 코드 복사

**복사 순서가 중요합니다.** 아래 순서대로 진행하세요.

각 파일마다:
1. Apps Script 편집기 왼쪽 **파일** 패널에서 **+** 버튼 클릭
2. **"스크립트"** 선택
3. 파일 이름 입력
4. 로컬의 해당 .gs 파일 내용을 전체 복사 → 붙여넣기

| 순서 | 파일 이름 | 복사할 로컬 파일 |
|------|----------|-----------------|
| 1 | `Config` | `apps-script/src/Config.gs` (이미 위에서 이름 변경함) |
| 2 | `Utils` | `apps-script/src/Utils.gs` |
| 3 | `Prompts` | `apps-script/src/Prompts.gs` |
| 4 | `GeminiAPI` | `apps-script/src/GeminiAPI.gs` |
| 5 | `WordPress` | `apps-script/src/WordPress.gs` |
| 6 | `Main` | `apps-script/src/Main.gs` |
| 7 | `Tests` | `apps-script/src/Tests.gs` |

> ⚠️ 파일 이름에 `.gs` 를 직접 입력하지 마세요. 자동으로 붙습니다.
> ⚠️ 복사할 때 코드 전체를 선택(Ctrl+A / Cmd+A)한 후 복사하세요.

### 2-4. 코드 저장

1. **Ctrl+S** (또는 Cmd+S) 또는 💾 아이콘 클릭
2. 모든 파일이 저장됩니다

완료 후 편집기 왼쪽 파일 목록이 아래와 같아야 합니다:
```
Config.gs
Utils.gs
Prompts.gs
GeminiAPI.gs
WordPress.gs
Main.gs
Tests.gs
```

## PART 3: Gemini API 키 발급

1. https://aistudio.google.com/app/apikey 접속
2. 구글 계정 로그인
3. **"Create API Key"** → **"Create API key in new project"**
4. 생성된 키 복사

5. Google Sheets로 돌아가서 **"설정"** 탭 → B1 셀에 API 키 붙여넣기

## PART 4: 권한 허용

처음 실행 시 한 번만 필요합니다.

1. Apps Script 편집기로 이동
2. 상단 함수 선택 드롭다운에서 **`testConfig`** 선택
3. **▶ 실행** 버튼 클릭
4. "승인 필요" 팝업 → **"권한 검토"** 클릭
5. 구글 계정 선택
6. **"고급"** 클릭 (왼쪽 하단)
7. **"(프로젝트 이름)(안전하지 않음)으로 이동"** 클릭
8. **"허용"** 클릭

> 이 경고는 정상입니다. 우리가 만든 스크립트이므로 안전합니다.

## PART 5: 단계별 테스트

### 테스트 1: Config 확인

1. Apps Script 편집기에서 함수 선택: **`testConfig`**
2. ▶ 실행
3. 하단 **"실행 로그"** 확인

**예상 결과:**
```
=== Config 테스트 ===
Gemini API 키: 설정됨 (AIzaSyBx...)
WordPress URL: 미설정
hasGeminiKey: true
hasWordPressConfig: false
=== Config 테스트 완료 ===
```

✅ `hasGeminiKey: true`가 나오면 성공!

### 테스트 2: 프롬프트 확인

1. 함수 선택: **`testPrompts`**
2. ▶ 실행

**예상 결과:**
```
=== Prompts 테스트 ===
톤: 친근한
길이: 2000자
생성된 프롬프트 (처음 200자): 다음 키워드에 대해 SEO 최적화된 한국어 블로그 글을...
이미지 프롬프트: 겨울 제주도 여행, blog thumbnail, eye-catching, flat illustration...
=== Prompts 테스트 완료 ===
```

✅ 프롬프트가 한국어로 잘 조합되면 성공!

### 테스트 3: Gemini 글 생성 (⚠️ 실제 API 호출)

1. 함수 선택: **`testGeminiText`**
2. ▶ 실행
3. 30초~1분 대기

**예상 결과:**
```
=== Gemini 텍스트 생성 테스트 ===
제목: 아침 운동의 놀라운 효과 7가지
본문 길이: 2847자
본문 (처음 300자): <h2>아침 운동, 왜 시작해야 할까?</h2>...
=== Gemini 텍스트 생성 테스트 완료 ===
```

✅ 제목과 본문이 나오면 성공! 글이 한국어로 잘 생성되는지 확인.

### 테스트 4: 이미지 생성 (⚠️ 실제 API 호출)

1. 함수 선택: **`testImagen`**
2. ▶ 실행
3. 30초~1분 대기

**예상 결과:**
```
=== Imagen 이미지 생성 테스트 ===
이미지 생성 성공!
MIME 타입: image/png
Base64 데이터 길이: 245632
=== Imagen 이미지 생성 테스트 완료 ===
```

✅ Base64 데이터가 나오면 성공!

> ⚠️ Imagen API가 아직 활성화되지 않은 경우 에러가 날 수 있음. 이 경우 글 생성만으로도 테스트 진행 가능.

### 테스트 5: 전체 파이프라인

1. **Google Sheets로 이동** → **"글감 생성"** 탭
2. 2행에 테스트 데이터 입력:

| 키워드 | 이미지생성 | 이미지스타일 | 자동포스팅 | 상태 |
|--------|-----------|------------|-----------|------|
| 겨울 제주도 여행 코스 | 없음 | | N | 대기 |

3. Apps Script 편집기에서 함수 선택: **`testFullPipeline`**
4. ▶ 실행
5. 1~2분 대기
6. Google Sheets로 돌아가서 결과 확인:
   - E열(상태): `완료`
   - F열(생성된 제목): AI가 생성한 제목
   - G열(생성된 본문): AI가 작성한 블로그 글

✅ 시트에 결과가 채워지면 핵심 기능 테스트 성공!

### 테스트 6: 커스텀 메뉴 확인

1. Google Sheets 탭을 **새로고침** (F5 또는 Cmd+R)
2. 상단 메뉴에 **"🤖 블로그 자동화"** 가 나타나는지 확인
3. 클릭하여 메뉴 항목이 보이는지 확인:
   - ▶️ 글 생성 실행
   - ⏰ 자동 실행 켜기 (10분 간격)
   - ⏹️ 자동 실행 끄기
   - 🔑 설정 확인

✅ 메뉴가 나타나면 성공!

### 테스트 7: 메뉴에서 실행

1. **"글감 생성"** 탭에 새 행 추가:

| 키워드 | 이미지생성 | 이미지스타일 | 자동포스팅 | 상태 |
|--------|-----------|------------|-----------|------|
| 봄맞이 인테리어 꿀팁 | 없음 | | N | 대기 |

2. 메뉴: **"🤖 블로그 자동화"** → **"▶️ 글 생성 실행"**
3. 1~2분 대기 → 결과 확인

✅ 메뉴에서도 정상 작동하면 모듈 1 기본 기능 완성!

## PART 6: WordPress 연동 테스트 (선택)

WordPress 테스트 블로그 세팅이 완료된 경우에만 진행합니다.

### 6-1. WordPress 정보 입력

**"설정"** 탭에 입력:

| | A열 | B열 |
|---|-----|-----|
| 2행 | `WordPress 주소` | `https://your-test-blog.instawp.xyz` |
| 3행 | `WordPress 아이디` | `admin` (또는 본인 아이디) |
| 4행 | `WordPress App Password` | (발급받은 Application Password) |

### 6-2. WordPress 연결 테스트

1. Apps Script 편집기에서 함수 선택: **`testWordPressConnection`**
2. ▶ 실행

**예상 결과:**
```
=== WordPress 연결 테스트 ===
HTTP 상태: 200
✅ WordPress 연결 성공!
=== WordPress 연결 테스트 완료 ===
```

### 6-3. 자동 포스팅 테스트

1. **"글감 생성"** 탭에 새 행:

| 키워드 | 이미지생성 | 이미지스타일 | 자동포스팅 | 상태 |
|--------|-----------|------------|-----------|------|
| 초보자 주식 투자 방법 | 없음 | | Y | 대기 |

2. 메뉴 → "▶️ 글 생성 실행"
3. 2~3분 대기
4. 확인:
   - 시트 H열(포스팅 결과): `포스팅 완료 (ID: xxx)`
   - WordPress 관리자 → 글 → 초안 목록에 새 글 확인

## 문제 발생 시

### "TypeError: Cannot read properties of null"
→ 시트 탭 이름이 정확한지 확인. `설정`, `글감 생성`, `프롬프트 설정` (띄어쓰기 주의)

### "Exception: Request failed for https://generativelanguage..."
→ API 키가 올바른지 확인. 설정 탭 B1 셀에 키가 정확히 입력되었는지 확인.

### "Gemini API 오류 (HTTP 429)"
→ 무료 한도 초과. 잠시 후 다시 시도.

### "WordPress 포스팅 실패 (HTTP 401)"
→ WordPress 아이디 또는 Application Password가 잘못됨.

### 실행 로그가 안 보여요
→ Apps Script 편집기 하단의 **"실행 로그"** 패널 확인. 안 보이면 **보기 → 로그** 메뉴.
