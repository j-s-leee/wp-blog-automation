## 비용 관련

### Q. 이 도구는 무료인가요?

**기본적으로 무료입니다.** 구글 시트와 Gemini API 모두 일정 사용량까지는 무료입니다.

- **구글 시트**: 완전 무료입니다.
- **Gemini API**: 구글에서 제공하는 무료 티어(Free Tier)가 있습니다. 무료 티어 기준(2025년 기준)으로 Gemini 1.5 Flash 모델은 하루 약 1,500회 요청까지 무료입니다. 일반적인 블로그 운영에는 충분한 양입니다.

---

### Q. Gemini API 무료 사용량은 얼마나 되나요?

구글 AI Studio의 무료 티어 기준(변경될 수 있으므로 최신 정보는 공식 페이지에서 확인하세요):

- **Gemini 1.5 Flash**: 하루 1,500회 요청 / 분당 15회 요청
- **Gemini 1.5 Pro**: 하루 50회 요청 / 분당 2회 요청

블로그 글 1개를 생성하는 데 보통 1~2회 요청이 사용됩니다. 하루에 수백 개의 글을 쓰지 않는 이상 무료 범위를 초과하기 어렵습니다.

---

### Q. 무료 사용량을 초과하면 어떻게 되나요?

무료 한도를 초과하면 에러가 발생하며 글 생성이 중단됩니다. 자동으로 유료 결제되지 않습니다. 유료 플랜으로 업그레이드하려면 Google Cloud Console에서 별도로 결제 수단을 등록해야 합니다.

---

### Q. 워드프레스 사용 비용은 따로 드나요?

이 도구 자체는 워드프레스에 대한 별도 비용을 청구하지 않습니다. 다만 워드프레스 호스팅 비용(사용 중인 호스팅 서비스 요금)은 별도입니다. WordPress.com 무료 플랜이나 직접 설치형(self-hosted) 워드프레스 모두 연동 가능합니다.

## 설치 관련

### Q. 서버가 필요한가요? 서버 설치나 설정이 복잡하지 않나요?

**서버가 전혀 필요하지 않습니다.** 이 도구는 100% 구글 시트 안에서 동작합니다. 구글의 서버(Apps Script)가 모든 처리를 대신해주기 때문에, 별도의 서버를 구축하거나 관리할 필요가 없습니다.

---

### Q. 프로그램을 따로 설치해야 하나요?

**아무것도 설치하지 않아도 됩니다.** 구글 시트 템플릿을 복사하는 것만으로 모든 기능이 바로 사용 가능합니다. 컴퓨터에 어떤 프로그램도 설치하지 않습니다.

---

### Q. 모바일(스마트폰)에서도 사용할 수 있나요?

키워드 입력과 결과 확인은 구글 시트 앱에서 가능합니다. 다만 상단 메뉴(🤖 블로그 자동화)는 PC 브라우저에서만 보입니다. 자동 실행을 켜두면 PC 없이도 백그라운드에서 처리됩니다. 키워드는 모바일에서 입력하고, 실제 실행은 자동 실행 기능을 활용하는 방식이 편리합니다.

---

### Q. 자동 실행 중에 컴퓨터를 꺼도 되나요?

**네, 꺼도 됩니다.** 자동 실행(⏰ 자동 실행 켜기)은 구글 서버에서 동작하기 때문에, 컴퓨터가 꺼져 있거나 인터넷이 끊겨 있어도 구글 서버가 10분마다 알아서 실행합니다. 결과는 구글 시트에 자동으로 저장됩니다.

---

### Q. 구글 계정이 여러 개인데 어떤 계정을 써야 하나요?

구글 시트를 복사한 계정과 Gemini API 키를 발급받은 계정이 같으면 가장 편리합니다. 다른 계정도 사용 가능하지만, 권한 허용 절차를 각각 진행해야 합니다.

---

## 사용 관련

### Q. 워드프레스 외에 티스토리나 네이버 블로그에도 자동 포스팅이 되나요?

현재는 **워드프레스만 자동 포스팅을 지원합니다.** 티스토리와 네이버 블로그는 공식 API가 제한적이거나 외부 연동이 어려워 현재 버전에서는 지원하지 않습니다. AI가 생성한 글은 구글 시트에 저장되므로, 복사-붙여넣기로 다른 플랫폼에 게시하실 수 있습니다.

---

### Q. 한 번에 몇 개의 글까지 생성할 수 있나요?

기술적으로는 무제한이지만, **한 번 실행에 권장 3~4개** 입니다. Apps Script는 한 번 실행에 최대 6분만 동작하는 제한이 있습니다. 6분이 지나면 자동으로 중단되고, 처리되지 못한 키워드는 다음 실행 때 이어서 처리됩니다. 자동 실행(10분 간격)을 켜두면 많은 키워드도 자동으로 순서대로 처리됩니다.

---

### Q. 글을 바로 게시하지 않고 임시저장(초안)으로 올릴 수 있나요?

현재 버전에서는 워드프레스에 자동 포스팅 시 **게시(published) 상태로 올라갑니다.** 임시저장(draft)으로 올리는 기능은 향후 업데이트에서 추가될 예정입니다. 지금 당장 임시저장이 필요하시면, AI가 생성한 글을 G열에서 복사해서 워드프레스 편집기에 직접 붙여넣는 방식을 사용하세요.

---

### Q. 생성된 글의 품질이 어떤가요? 수정이 많이 필요한가요?

Gemini AI가 생성하는 글은 일반적으로 읽기 편한 수준의 블로그 글입니다. 키워드가 구체적일수록 글 품질이 높아집니다. 예를 들어 "여행"보다 "겨울 제주도 3박 4일 가족 여행 코스" 처럼 구체적으로 입력하면 훨씬 좋은 결과가 나옵니다. SEO 최적화나 개인 경험을 담은 글로 만들기 위해 일부 수정하시는 것을 권장합니다.

---

### Q. 프롬프트를 직접 수정할 수 있나요?

**네, 가능합니다.** **"🎨 프롬프트 설정"** 탭에서 AI에게 주는 지시문을 자유롭게 수정하실 수 있습니다. 원하는 글의 톤(친근하게, 전문적으로), 구성(서론-본론-결론), 길이, 포함할 섹션 등을 지정해보세요. 프롬프트를 잘 조정할수록 원하는 스타일의 글이 나옵니다.

---

### Q. 이미지 스타일 3가지(일러스트/사진풍/미니멀)의 차이가 뭔가요?

| 스타일 | 느낌 | 추천 블로그 유형 |
|--------|------|-----------------|
| **일러스트** | 따뜻하고 감성적인 그림체 | 여행, 음식, 라이프스타일 |
| **사진풍** | 실제 사진처럼 사실적인 이미지 | 제품 소개, 정보성 글, 뉴스 |
| **미니멀** | 심플하고 깔끔한 아이콘/도형 스타일 | IT, 비즈니스, 투자, 기술 블로그 |

이미지 생성을 사용하려면 B열 **이미지생성** 에 `Y` 를 입력하고 C열 **이미지스타일** 에 원하는 스타일을 입력하세요.

---

### Q. AI가 생성한 이미지를 상업적으로 사용해도 되나요?

Gemini가 생성한 이미지의 저작권 정책은 구글의 이용약관을 따릅니다. 일반적으로 개인 블로그 운영 목적으로는 사용 가능하지만, 상업적 대규모 활용 전에는 [Google의 이용약관](https://ai.google.dev/terms)을 직접 확인하시기 바랍니다. 항상 AI 생성 이미지임을 밝히는 것이 권장됩니다.

---

### Q. 여러 개의 워드프레스 블로그에 동시에 포스팅할 수 있나요?

현재 버전에서는 **하나의 워드프레스 블로그만 연결** 할 수 있습니다. 여러 블로그를 운영하신다면, 구글 시트 템플릿을 블로그마다 하나씩 복사해서 각각 설정하시면 됩니다.

---

## 트러블슈팅

### Q. "Google에서 확인하지 않은 앱" 경고가 떴어요. 안전한가요?

**안전합니다.** 이 경고는 개인이나 소규모 팀이 배포한 Apps Script에 대해 구글이 자동으로 표시하는 것입니다. 구글이 공식적으로 검토/인증하지 않았다는 뜻이지, 악성 코드가 있다는 뜻이 아닙니다.

이 도구의 코드는 다음 기능만 수행합니다.
- 구글 시트 읽기/쓰기
- Gemini API 호출 (AI 글 생성)
- WordPress REST API 호출 (자동 포스팅, 선택사항)

"고급" 링크를 클릭한 후 "(앱 이름)(으)로 이동"을 클릭해서 허용하시면 됩니다.

---

### Q. 메뉴가 안 보여요

구글 시트를 열면 메뉴가 로드되는 데 몇 초가 걸립니다. 페이지를 새로고침(F5 또는 Ctrl+R)하면 대부분 해결됩니다. 그래도 안 나타나면 브라우저 캐시를 지우고 다시 시도해보세요.

---

### Q. 글 생성 중에 "에러" 상태가 됐어요

가장 흔한 원인과 해결법:

| 에러 원인 | 확인 방법 | 해결법 |
|-----------|-----------|--------|
| API 키 오류 | H열 에러 메시지 확인 | API 키 재발급 후 재입력 |
| 무료 사용량 초과 | "quota exceeded" 메시지 | 하루 뒤 다시 시도 |
| 네트워크 오류 | "network error" 메시지 | 잠시 후 재시도 |
| WordPress 연결 오류 | "401" 또는 "403" 메시지 | 앱 비밀번호 재확인 |

에러가 발생한 행의 E열 상태를 다시 **"대기"** 로 바꾸면 다음 실행 때 재시도합니다.

---

### Q. 자동 실행을 껐는데도 계속 실행되는 것 같아요

메뉴에서 **"⏹️ 자동 실행 끄기"** 를 다시 한 번 클릭해보세요. 그래도 계속된다면 Apps Script 편집기에서 직접 트리거를 삭제할 수 있습니다. 구글 시트에서 **확장 프로그램 → Apps Script** 를 열고, 왼쪽 메뉴에서 **트리거(시계 아이콘)** 를 클릭해서 등록된 트리거를 삭제하세요.

---

### Q. 구글 시트를 다른 사람과 공유하면 그 사람도 글 생성 기능을 쓸 수 있나요?

**편집 권한이 있으면 가능합니다.** 단, 처음 실행 시 그 사람의 구글 계정으로도 권한 허용 절차를 진행해야 합니다. 또한 구글 계정당 Apps Script 실행 할당량이 적용되므로, 여러 사람이 동시에 많이 사용하면 제한에 걸릴 수 있습니다.

---

### Q. API 키가 유출된 것 같아요

[Google AI Studio](https://aistudio.google.com/app/apikey) 에서 즉시 해당 API 키를 삭제하고 새 키를 발급받으세요. 구글 시트의 설정 탭에도 새 키로 업데이트하시면 됩니다. 구글 시트를 다른 사람과 공유할 때는 API 키가 입력된 설정 탭에 대한 접근 권한을 주의하세요.

---

## 기타

### Q. 도구가 업데이트되면 어떻게 적용하나요?

현재는 수동 업데이트 방식입니다. 새 버전의 템플릿이 배포되면 기존 시트의 키워드 데이터를 새 시트에 복사하고, 설정 탭의 API 키와 워드프레스 정보를 다시 입력하시면 됩니다. 향후에는 더 간편한 업데이트 방식을 제공할 예정입니다.

---

### Q. 이 도구로 만든 글이 검색 엔진(SEO)에 잘 노출되나요?

AI가 생성한 글 자체가 SEO를 보장하지는 않습니다. 검색 노출을 높이려면:

1. **구체적인 키워드** 를 사용하세요. (예: "다이어트" 대신 "30대 여성 건강한 다이어트 식단")
2. **프롬프트 설정** 에서 AI에게 "SEO를 고려한 글을 써줘", "키워드를 자연스럽게 2~3회 포함해줘" 등의 지시를 추가하세요.
3. 생성된 글에 개인 경험이나 사진을 추가하면 콘텐츠 품질이 높아집니다.

---

### Q. 구글 계정 없이도 쓸 수 있나요?

아니요. 구글 시트와 Gemini API 모두 구글 계정이 필요합니다. 구글 계정은 무료로 만들 수 있습니다.

---

### Q. 사용 도중 문제가 생기면 어디에 문의하나요?

이 도구의 코드는 오픈소스입니다. 문제가 생기면 다음을 먼저 확인해보세요:

1. 이 FAQ 문서
2. [사용자 매뉴얼](./user-manual.md)의 "문제 해결" 섹션

그래도 해결이 안 되면 문제 상황(어떤 동작을 했는지, 어떤 에러 메시지가 나왔는지)을 구체적으로 설명해주시면 도움받으실 수 있습니다.
