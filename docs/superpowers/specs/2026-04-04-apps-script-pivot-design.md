# 블로그 자동화 도구 — Apps Script 전환 설계서

> 작성일: 2026-04-04
> 상태: 확정

## 1. 배경 및 전환 사유

### 기존 구조 (n8n + Docker + Oracle Cloud)
- n8n 셀프호스팅 on Oracle Cloud Free Tier
- Docker Compose (n8n + Caddy + WordPress + MySQL)
- 구매자가 서버 세팅을 직접 수행

### 전환 사유
- **Oracle Cloud 가입 실패 리스크**: 카드 인증, 위치 마스킹 등으로 가입 불가한 사용자 다수 예상
- **CS 부담**: 비개발자 대상 제품에서 SSH, Docker, 서버 관리 요구는 CS 지옥
- **경쟁사 대비**: 경쟁 상품(79~175만원)은 판매자가 세팅 대행. 우리는 저가 전략이므로 세팅 노동 최소화 필수
- **스케일**: 세팅 대행 없이 파일 납품만으로 판매량 확장 가능해야 함

### 전환 방향
n8n + 서버 → **Google Apps Script** (서버 완전 제거)
- 구매자: Google Sheets 복사 → API 키 입력 → 사용 (세팅 5분)
- 판매자: 시트 링크 1개 납품 (세팅 노동 0)

## 2. 전체 아키텍처

```
[구매자가 받는 것]
Google Sheets 템플릿 (Apps Script 내장)
  ├── 모듈 1: 글감 생성 + 포스팅
  ├── 모듈 2: 쿠팡파트너스 (Phase 2)
  └── 모듈 3: 알리익스프레스 (Phase 3)

[구매자가 하는 것]
1. 구글 시트 "사본 만들기"
2. 설정 시트에서 API 키 입력
3. 키워드 입력 → 버튼 클릭 or 자동 실행

[기술 스택]
- Google Apps Script (실행 환경)
- Google Sheets (UI + 데이터 저장)
- Gemini API (텍스트 생성 + 이미지 생성)
- WordPress REST API (자동 포스팅, 선택)
```

서버, Docker, n8n, 데이터베이스 일체 불필요.

## 3. Google Sheets 구조

### 탭 1: ⚙️ 설정

구매자가 한 번만 입력하는 설정값.

| 항목 | 값 (예시) | 설명 |
|------|----------|------|
| Gemini API 키 | `AIzaSy...` | 글 생성 + 이미지 생성 |
| WordPress 주소 | `https://myblog.com` | 자동 포스팅 시 (선택) |
| WordPress 아이디 | `admin` | (선택) |
| WordPress App Password | `xxxx xxxx xxxx` | (선택) |

### 탭 2: 📝 글감 생성

메인 작업 시트.

| 키워드 | 이미지생성 | 이미지스타일 | 자동포스팅 | 상태 | 생성된 제목 | 생성된 본문 | 포스팅 결과 |
|--------|-----------|------------|-----------|------|-----------|-----------|-----------|

- **상태 값**: 대기 → 처리 중 → 완료 / 에러
- **이미지스타일**: 일러스트 / 사진풍 / 미니멀 (드롭다운)
- **자동포스팅**: Y / N (드롭다운)

### 탭 3: 🎨 프롬프트 설정

구매자가 글 스타일을 커스터마이징하는 탭.

| 항목 | 값 |
|------|-----|
| 글 톤 | 친근한 / 전문적 / 캐주얼 (드롭다운) |
| 글 길이 | 1500자 / 2000자 / 3000자 (드롭다운) |
| 커스텀 프롬프트 | (고급 사용자용, 비워두면 기본값) |

## 4. Apps Script 핵심 로직

### 파일 구조

```
Apps Script 프로젝트/
├── Main.gs              # 메인 실행 로직 (트리거, 메뉴)
├── GeminiAPI.gs         # Gemini 텍스트 생성 + Imagen 이미지 생성
├── WordPress.gs         # WP REST API 포스팅 + 미디어 업로드
├── Config.gs            # 설정 시트에서 값 읽기
├── Prompts.gs           # 프롬프트 템플릿 조합
└── Utils.gs             # 공통 유틸 (에러 핸들링, 로깅)
```

### 실행 흐름

```
트리거 (수동 버튼 or 시간 트리거)
  → "글감 생성" 시트에서 상태="대기"인 행 찾기
  → 행 단위로 처리:
    1. 상태를 "처리 중"으로 변경
    2. 프롬프트 조합 (키워드 + 프롬프트 설정 탭 값)
    3. Gemini API 호출 → 제목/본문 파싱
    4. 이미지생성=Y이면 → Imagen API 호출 → base64 이미지 반환
    5. 자동포스팅=Y이면 → WordPress에 글 + 이미지 업로드
    6. 결과를 시트에 기록 (제목, 본문, 상태="완료")
  → 에러 발생 시 상태="에러" + 에러 메시지 기록
```

### 실행 방식

- **수동**: 시트 상단 커스텀 메뉴 → "글 생성 실행" 클릭
- **자동**: Apps Script 시간 트리거 (10분 간격) — "대기" 상태인 행을 자동 처리

### Apps Script 제한 대응

| 제한 | 값 | 대응 |
|------|-----|------|
| 실행 시간 | 6분/회 | 행 1개씩 처리, 남은 건 다음 트리거에서 이어서 |
| 일일 실행 | 90분/일 | 글 1개당 ~1분이면 하루 90개 가능 |
| URL Fetch | 20,000회/일 | 글 1개당 API 호출 3~4회 → 하루 5,000개 가능 |
| 트리거 간격 | 최소 1분 | 10분 간격으로 설정 |

## 5. 모듈 분리 및 판매 구조

### 모듈 구성

| 모듈 | 내용 | 시트 |
|------|------|------|
| 모듈 1 | 블로그 글감 자동화 | 글감 전용 시트 |
| 모듈 2 | 쿠팡파트너스 자동화 | 쿠팡 전용 시트 |
| 모듈 3 | 알리익스프레스 자동화 | 알리 전용 시트 |
| 번들 | 올인원 통합 | 올인원 시트 |

### 판매 전략

- 모듈 1개 구매 → 해당 모듈 시트 제공
- 모듈 2개 이상 구매 → 올인원 통합 시트 제공 (자동 업그레이드)
- 처음부터 번들 구매 → 올인원 시트 + 가격 할인

### 구매자 여정

```
글감 자동화만 구매 → 글감 시트 사용
  → 만족 → 쿠팡 추가 구매
    → 올인원 시트 제공 (기존 설정 마이그레이션 가이드 포함)
    → "여기서 다 사면 하나로 관리되네" → 알리도 추가 구매
```

### 번들의 차별점

번들은 단순 묶음 할인이 아니라 **모듈 간 연동 기능** 포함:
- 예: 쿠팡 상품을 블로그 글에 자동 삽입
- 개별 시트로는 불가, 올인원에서만 가능

### 가격대 (예시, 시장 반응 보고 조절)

| 상품 | 가격대 | 납품물 |
|------|--------|--------|
| 블로그 글감 자동화 | 15~25만원 | 시트 링크 + 매뉴얼 PDF |
| 쿠팡파트너스 자동화 | 15~25만원 | 시트 링크 + 매뉴얼 PDF |
| 올인원 번들 | 35~50만원 | 통합 시트 + 매뉴얼 PDF |
| 프리미엄 (1:1 세팅) | +10만원 | 화면 공유로 세팅 도움 |

경쟁사 79~175만원 대비 절반 이하 가격, 세팅 난이도는 훨씬 낮음.

## 6. 개발 계획

### 기존 코드 처리
- `infrastructure/`, n8n 워크플로우 → `archive/n8n-prototype/`로 이동
- 프롬프트 템플릿, FAQ 내용 → Apps Script 버전에서 재활용
- 기존 매뉴얼 → Apps Script 버전으로 새로 작성

### 개발 순서

```
Phase 1: 모듈 1 — 블로그 글감 자동화
  1. 올인원 시트 기본 구조 (설정/글감 생성/프롬프트 설정 탭)
  2. Apps Script 핵심 로직 (Gemini 글 생성 + 시트 기록)
  3. 이미지 생성 (Imagen API + base64 처리)
  4. WordPress 자동 포스팅 (선택 기능)
  5. 에러 핸들링 + 시간 트리거 설정
  6. 테스트 (직접 돌려보기)
  7. 모듈 1 전용 시트 분리 (올인원에서 추출)
  8. 사용자 매뉴얼 + FAQ (Apps Script 버전)

Phase 2: 모듈 2 — 쿠팡파트너스 자동화
Phase 3: 모듈 3 — 알리익스프레스 자동화
Phase 4: 크몽 출시 (상품 페이지, 가격 확정)
```

### 프로젝트 디렉토리 구조

```
blog-automation-tool/
├── archive/
│   └── n8n-prototype/        # 기존 n8n 코드 보관
├── apps-script/
│   ├── src/                  # Apps Script 소스코드
│   │   ├── Main.gs
│   │   ├── GeminiAPI.gs
│   │   ├── WordPress.gs
│   │   ├── Config.gs
│   │   ├── Prompts.gs
│   │   └── Utils.gs
│   └── templates/
│       └── prompt-templates.txt
├── docs/
│   ├── user-manual.md        # Apps Script 버전 매뉴얼
│   ├── faq.md                # 업데이트된 FAQ
│   └── images/
└── .gitignore
```

## 7. 리스크 및 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| Apps Script 6분 제한 | 긴 글 생성 시 타임아웃 | 행 단위 처리, 트리거 체인 |
| Gemini API 무료 한도 초과 | 대량 생성 시 일시 중단 | 사용량 안내, 유료 전환 가이드 |
| Google 정책 변경 | Apps Script 제한 강화 가능 | 코드가 표준 JS라 다른 플랫폼 이식 가능 |
| 구매자 시트 복사 후 재배포 | 불법 공유 | 시트 보호 + 이용약관으로 대응 |
| WordPress API 인증 복잡 | 비개발자에게 어려움 | Application Password 발급 가이드 상세화 |
