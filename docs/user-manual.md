> 이 가이드를 처음부터 끝까지 따라하시면, 구글 시트에 키워드만 입력하면 AI가 자동으로 블로그 글을 작성해주는 시스템을 바로 쓰실 수 있습니다.
>
> **서버 설치 없음. 프로그램 설치 없음. 구글 시트 하나로 모두 해결됩니다.**

## 1. 시작하기 전에 준비할 것

아래 항목만 있으면 됩니다. 복잡한 준비물은 전혀 없습니다.

| 준비물 | 설명 | 비용 |
|--------|------|------|
| 구글 계정 | 구글 시트와 Gemini API 사용 | 무료 |
| 워드프레스 블로그 (선택) | 글을 자동으로 올릴 블로그 | 선택사항 — 없어도 됩니다 |

**워드프레스가 없어도 괜찮습니다.** 구글 시트 안에 AI가 쓴 글이 자동으로 저장되기 때문에, 워드프레스 연결은 나중에 언제든 추가하실 수 있습니다.

## STEP 1: 구글 시트 복사하기

### 1-1. 템플릿 시트 열기

아래 링크를 클릭해서 템플릿 구글 시트를 여세요.

**👉 [블로그 자동화 도구 템플릿 열기] (링크를 여기에 입력하세요)**

> [📸 스크린샷: 템플릿 구글 시트가 열린 화면 — 상단에 "보기 전용" 표시가 있는 상태]

### 1-2. 내 구글 드라이브로 복사하기

화면 상단 메뉴에서 **파일 → 사본 만들기** 를 클릭합니다.

> [📸 스크린샷: 상단 메뉴 "파일"을 클릭했을 때 나오는 드롭다운 — "사본 만들기" 항목 강조]

이름은 원하시는 대로 바꾸셔도 됩니다. **확인** 버튼을 누르면 내 구글 드라이브에 시트가 복사됩니다.

> [📸 스크린샷: "사본 만들기" 팝업창 — 파일명 입력칸과 확인 버튼]

복사가 완료되면 새 탭에 **내 시트**가 열립니다. 이제부터는 이 시트를 사용하시면 됩니다.

> [📸 스크린샷: 복사된 시트가 열린 화면 — 하단에 "⚙️ 설정", "📝 글감 생성", "🎨 프롬프트 설정" 탭 3개가 보임]

## STEP 2: Gemini API 키 발급받기

Gemini API 키는 AI(인공지능)가 글을 쓸 수 있도록 허가하는 비밀번호 같은 것입니다. 구글에서 무료로 발급해줍니다.

### 2-1. Google AI Studio 접속

아래 주소를 새 탭에서 여세요.

**👉 https://aistudio.google.com/app/apikey**

구글 계정으로 로그인이 필요합니다. 구글 시트를 만든 계정과 같은 계정을 사용하시는 것을 권장합니다.

> [📸 스크린샷: Google AI Studio의 API Key 페이지 — "Create API key" 버튼이 보이는 화면]

### 2-2. API 키 만들기

**"Create API key"** 버튼을 클릭합니다.

> [📸 스크린샷: "Create API key in new project" 또는 기존 프로젝트 선택 화면]

"Create API key in new project"를 선택하면 자동으로 새 프로젝트가 만들어지면서 API 키가 생성됩니다.

### 2-3. API 키 복사하기

생성된 API 키가 화면에 표시됩니다. 이 키는 `AIza`로 시작하는 긴 문자열입니다.

> [📸 스크린샷: API 키가 생성된 화면 — 키 문자열 옆에 복사 아이콘이 있음]

**복사 아이콘을 클릭**해서 키를 복사해두세요. 다음 단계에서 바로 사용합니다.

> ⚠️ **주의**: API 키는 비밀번호처럼 소중하게 관리하세요. 다른 사람과 공유하지 마세요.

---

## STEP 3: API 키 입력하기

복사한 API 키를 구글 시트에 입력할 차례입니다.

### 3-1. "⚙️ 설정" 탭 클릭

시트 하단의 탭 중에서 **"⚙️ 설정"** 탭을 클릭합니다.

> [📸 스크린샷: 시트 하단 탭 — "⚙️ 설정" 탭이 선택된 상태]

### 3-2. API 키 입력

**"Gemini API 키"** 항목 오른쪽 칸(B1 셀)을 클릭하고, 복사해 둔 API 키를 붙여넣기(Ctrl+V 또는 Cmd+V) 합니다.

> [📸 스크린샷: 설정 탭의 B1 셀에 API 키가 입력된 모습 — 키의 일부분만 보이도록 가림 처리]

입력 후 **Enter** 키를 눌러 저장합니다.

## STEP 4: 스크립트 권한 허용하기

구글 시트 안의 자동화 스크립트가 처음 실행될 때, 구글이 "이 스크립트를 허용하시겠어요?" 라고 묻습니다. 이것은 완전히 정상적인 과정입니다.

### 4-1. 메뉴에서 설정 확인 실행

시트 상단 메뉴에서 **"🤖 블로그 자동화" → "🔑 설정 확인"** 을 클릭합니다.

> [📸 스크린샷: 상단 메뉴바에 "🤖 블로그 자동화" 메뉴가 보이는 화면]

> [📸 스크린샷: 메뉴를 열었을 때 "▶️ 글 생성 실행", "⏰ 자동 실행 켜기", "⏹️ 자동 실행 끄기", "🔑 설정 확인" 항목이 보이는 화면]

> 💡 **메뉴가 안 보인다면?** 페이지를 새로고침(F5)하면 메뉴가 나타납니다. 시트를 처음 열었을 때 메뉴가 로드되는 데 몇 초가 걸릴 수 있습니다.

### 4-2. 권한 허용 팝업 처리

"승인 필요" 팝업이 뜨면 **"계속"** 버튼을 클릭합니다.

> [📸 스크린샷: "이 스크립트를 실행하려면 승인이 필요합니다" 팝업창 — "계속" 버튼 강조]

### 4-3. 구글 계정 선택

내 구글 계정을 선택합니다.

> [📸 스크린샷: 구글 계정 선택 화면]

### 4-4. "안전하지 않은 앱" 경고 처리

"Google에서 확인하지 않은 앱" 또는 "이 앱은 안전하지 않을 수 있습니다"라는 경고 화면이 나올 수 있습니다.

> [📸 스크린샷: "Google에서 확인하지 않은 앱" 경고 화면 — 왼쪽 아래에 작은 "고급" 또는 "Advanced" 링크가 있음]

**걱정하지 않으셔도 됩니다.** 이 경고는 직접 배포한 앱에 대해 구글이 자동으로 표시하는 것으로, 코드가 위험하다는 뜻이 아닙니다.

아래와 같이 진행하세요:

1. 화면 왼쪽 아래의 **"고급"** 링크를 클릭합니다.

> [📸 스크린샷: "고급" 링크를 클릭하면 아래에 추가 텍스트가 펼쳐지는 화면]

2. 펼쳐진 내용 아래 **"(프로젝트 이름)(으)로 이동"** 링크를 클릭합니다.

> [📸 스크린샷: "(앱 이름)(으)로 이동" 링크가 강조된 화면]

3. 권한 목록을 확인하고 **"허용"** 버튼을 클릭합니다.

> [📸 스크린샷: 권한 요청 목록 — "Google 스프레드시트의 데이터 보기 및 관리" 등의 항목이 보임 — 하단에 "허용" 버튼]

### 4-5. 설정 확인 완료

권한 허용 후 다시 메뉴에서 **"🔑 설정 확인"** 을 실행하면 아래와 같은 팝업이 뜹니다.

```
=== 설정 상태 ===

Gemini API 키: ✅ 설정됨
WordPress 연동: ❌ 미설정 (자동 포스팅 불가)
```

"Gemini API 키: ✅ 설정됨" 이 표시되면 성공입니다! WordPress는 아직 설정하지 않았으니 ❌로 나오는 것이 정상입니다.

> [📸 스크린샷: 설정 상태 팝업창 — "Gemini API 키: ✅ 설정됨" 이 보이는 화면]

## STEP 5: 첫 번째 글 생성 테스트

이제 실제로 AI가 블로그 글을 써주는지 테스트해봅시다!

### 5-1. "📝 글감 생성" 탭 클릭

시트 하단에서 **"📝 글감 생성"** 탭을 클릭합니다.

> [📸 스크린샷: "📝 글감 생성" 탭이 선택된 화면 — 헤더 행에 "키워드", "이미지생성", "이미지스타일", "자동포스팅", "상태", "생성된 제목", "생성된 본문", "포스팅 결과" 컬럼이 보임]

### 5-2. 테스트 데이터 입력

2번째 행(헤더 바로 아래)에 아래와 같이 입력합니다.

| 열 | 항목 | 입력값 |
|----|------|--------|
| A열 (키워드) | 글 주제 키워드 | `겨울 제주도 여행 코스` |
| B열 (이미지생성) | 이미지 생성 여부 | `없음` |
| C열 (이미지스타일) | 이미지 스타일 | (비워두세요) |
| D열 (자동포스팅) | 워드프레스 자동 게시 여부 | `N` |
| E열 (상태) | 처리 상태 | `대기` |

> [📸 스크린샷: "글감 생성" 시트의 2번 행에 위 데이터가 입력된 모습]

> 💡 **중요**: E열 상태를 반드시 **"대기"** 로 입력해야 처리됩니다. 다른 글자를 입력하면 건너뜁니다.

### 5-3. 글 생성 실행

상단 메뉴에서 **"🤖 블로그 자동화" → "▶️ 글 생성 실행"** 을 클릭합니다.

> [📸 스크린샷: 메뉴에서 "▶️ 글 생성 실행"을 클릭하는 화면]

### 5-4. 생성 완료 확인

AI가 글을 쓰는 동안 E열 상태가 **"처리 중"** 으로 바뀝니다. 보통 30초~2분 정도 기다리시면 됩니다.

완료되면 상태가 **"완료"** 로 바뀌고, F열과 G열에 AI가 작성한 제목과 본문이 채워집니다.

> [📸 스크린샷: 글 생성이 완료된 화면 — E열에 "완료", F열에 제목, G열에 본문이 채워진 상태]

G열의 셀을 클릭하면 AI가 작성한 글 전체를 확인할 수 있습니다.

> [📸 스크린샷: G열 셀을 클릭했을 때 하단 미리보기 또는 셀 확장으로 글 내용이 보이는 화면]

**축하합니다! 기본 설정이 모두 완료되었습니다.** 이제 키워드만 입력하면 AI가 자동으로 블로그 글을 써줍니다.

## STEP 6: 워드프레스 자동 포스팅 설정 (선택사항)

워드프레스 블로그가 있으시면 AI가 글을 생성함과 동시에 자동으로 게시까지 해드립니다. 워드프레스가 없으시면 이 단계를 건너뛰셔도 됩니다.

### 6-1. 워드프레스 애플리케이션 비밀번호 만들기

일반 로그인 비밀번호 대신 **애플리케이션 비밀번호**를 사용합니다. 이것은 외부 프로그램이 워드프레스에 접근할 때 쓰는 별도의 비밀번호로, 기존 비밀번호와 독립적으로 관리됩니다.

1. 워드프레스 관리자 페이지에 로그인합니다. (주소: `내_블로그_주소/wp-admin`)

> [📸 스크린샷: 워드프레스 관리자 대시보드 화면]

2. 왼쪽 메뉴에서 **사용자 → 프로필** 로 이동합니다.

> [📸 스크린샷: 워드프레스 왼쪽 메뉴 — "사용자" > "프로필" 항목]

3. 페이지를 아래로 스크롤하면 **"애플리케이션 비밀번호"** 섹션이 나옵니다.

> [📸 스크린샷: 프로필 페이지 하단의 "애플리케이션 비밀번호" 섹션]

4. "새 애플리케이션 비밀번호 이름" 칸에 **"블로그 자동화"** 라고 입력하고 **"새 애플리케이션 비밀번호 추가"** 버튼을 클릭합니다.

> [📸 스크린샷: 애플리케이션 비밀번호 이름 입력 후 버튼 클릭하는 화면]

5. 생성된 비밀번호가 화면에 딱 한 번만 표시됩니다. **반드시 복사해두세요.** 창을 닫으면 다시 볼 수 없습니다.

> [📸 스크린샷: 생성된 애플리케이션 비밀번호 — `xxxx xxxx xxxx xxxx xxxx xxxx` 형식의 문자열]

> ⚠️ **주의**: 비밀번호는 공백 포함해서 그대로 복사하세요. 공백을 제거하지 않아도 됩니다.

### 6-2. 구글 시트에 워드프레스 정보 입력

**"⚙️ 설정"** 탭으로 돌아가서 아래 3가지 항목을 입력합니다.

| 항목 | 입력 내용 | 예시 |
|------|-----------|------|
| WordPress 주소 | 블로그 주소 (끝에 `/` 없이) | `https://myblog.com` |
| WordPress 아이디 | 워드프레스 로그인 아이디 | `admin` |
| WordPress App Password | 방금 복사한 애플리케이션 비밀번호 | `xxxx xxxx xxxx xxxx` |

> [📸 스크린샷: 설정 탭에 워드프레스 정보 3가지가 모두 입력된 화면]

### 6-3. 연결 확인

**"🤖 블로그 자동화" → "🔑 설정 확인"** 을 실행합니다. 아래와 같이 표시되면 성공입니다.

```
=== 설정 상태 ===

Gemini API 키: ✅ 설정됨
WordPress 연동: ✅ 설정됨
```

> [📸 스크린샷: 설정 상태 팝업 — 두 항목 모두 ✅로 표시된 화면]

### 6-4. 자동 포스팅 테스트

**"📝 글감 생성"** 탭에서 새 행을 추가하고 이번에는 **D열 자동포스팅을 `Y`** 로 설정한 뒤 글 생성을 실행해보세요.

완료 후 H열 **"포스팅 결과"** 에 `✅ 포스팅 완료: https://...` 와 같은 링크가 표시되면 자동 포스팅 성공입니다!

> [📸 스크린샷: H열 포스팅 결과에 링크가 표시된 화면]

## 일상적인 사용법

설정이 완료되었다면 이제 매일 이렇게 사용하시면 됩니다.

### 수동으로 글 생성하기

1. **"📝 글감 생성"** 탭에서 새 행에 키워드를 입력합니다.
2. E열 상태를 **"대기"** 로 입력합니다.
3. **"🤖 블로그 자동화" → "▶️ 글 생성 실행"** 을 클릭합니다.
4. 완료되면 F열(제목)과 G열(본문)에 결과가 나타납니다.

### 한 번에 여러 글 생성하기 (배치 생성)

여러 키워드를 한 번에 처리할 수 있습니다.

1. 여러 행에 각각 키워드를 입력합니다.
2. 각 행의 E열을 모두 **"대기"** 로 설정합니다.
3. **"▶️ 글 생성 실행"** 을 한 번만 클릭합니다.

AI가 위에서부터 순서대로 모든 "대기" 상태의 글을 자동으로 생성합니다. 한 번 실행에 너무 많은 글(대략 5개 이상)을 처리하면 구글의 시간 제한(6분)에 걸릴 수 있으니, 한 번에 3~4개씩 처리하는 것을 권장합니다.

### 자동 실행 켜기 (10분마다 자동 처리)

키워드를 미리 많이 입력해두고 AI가 자동으로 처리하게 하고 싶을 때 사용합니다.

1. **"🤖 블로그 자동화" → "⏰ 자동 실행 켜기"** 를 클릭합니다.
2. 이후부터 **10분마다** 자동으로 "대기" 상태인 키워드를 처리합니다.
3. 컴퓨터를 꺼도 구글 서버가 계속 실행합니다.

> [📸 스크린샷: "자동 실행이 활성화되었습니다" 팝업창]

### 자동 실행 끄기

더 이상 자동으로 실행되지 않게 하려면 **"🤖 블로그 자동화" → "⏹️ 자동 실행 끄기"** 를 클릭합니다.

### 이미지 스타일 선택

B열 **이미지생성** 을 `Y`로 설정하면 AI가 이미지도 함께 만들어줍니다. C열 **이미지스타일** 에서 아래 3가지 중 하나를 선택할 수 있습니다.

| 스타일 | 설명 | 적합한 블로그 유형 |
|--------|------|------------------|
| `일러스트` | 부드럽고 따뜻한 일러스트 풍 | 여행, 라이프스타일, 음식 |
| `사진풍` | 사실적인 사진 느낌 | 제품 리뷰, 정보성 글 |
| `미니멀` | 깔끔하고 단순한 디자인 | 비즈니스, IT, 전문 정보 |

### 프롬프트 커스터마이징

**"🎨 프롬프트 설정"** 탭에서 AI에게 주는 지시문(프롬프트)을 직접 수정할 수 있습니다. 글의 톤앤매너, 구성, 길이 등을 원하는 대로 조정해보세요.

## 문제 해결

### "🤖 블로그 자동화" 메뉴가 안 보여요

- 페이지를 **새로고침(F5)** 해주세요. 시트가 처음 열릴 때 메뉴 로드에 몇 초가 걸립니다.
- 그래도 안 나타나면 시트를 닫았다가 다시 열어보세요.

### "처리할 대기 항목이 없습니다" 팝업이 떠요

- **"📝 글감 생성"** 탭에서 E열(상태)이 정확히 **"대기"** 라고 입력되어 있는지 확인하세요.
- 띄어쓰기나 오타가 없는지 확인하세요. "대 기", "대기 " 처럼 공백이 포함되면 인식이 안 됩니다.

### "Gemini API 키가 설정되지 않았습니다" 팝업이 떠요

- **"⚙️ 설정"** 탭에서 B1 셀에 API 키가 제대로 입력되어 있는지 확인하세요.
- API 키 앞뒤에 불필요한 공백이 없는지 확인하세요.

### 상태가 "에러"로 바뀌었어요

- H열(포스팅 결과) 또는 G열에 에러 메시지가 표시됩니다. 그 메시지를 확인하세요.
- 가장 흔한 원인: API 키 오류 (키를 잘못 입력했거나 만료됨), 인터넷 연결 문제.
- API 키를 [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) 에서 다시 확인하거나 새로 발급받아보세요.

### 글이 한 개밖에 안 생성되고 멈춰요

- Apps Script는 한 번 실행에 최대 6분까지만 동작합니다. 여러 개를 입력했을 때 시간이 초과되면 다음 실행 때 이어서 처리됩니다.
- **자동 실행(10분 간격)** 을 켜두면 자동으로 이어서 처리됩니다.

### 워드프레스 포스팅이 안 돼요

- **"⚙️ 설정"** 탭의 WordPress 주소가 `https://myblog.com` 형식으로 입력되었는지 확인하세요. 끝에 `/` 가 있으면 안 됩니다.
- 애플리케이션 비밀번호를 다시 확인하세요. 비밀번호 생성 후 창을 닫기 전에 복사하지 못했다면, 새로 만들어야 합니다.
- WordPress 관리자 → **설정 → 고유주소** 에서 고유주소 구조가 설정되어 있는지 확인하세요. (기본 설정은 REST API 사용 불가)

### "안전하지 않은 앱" 경고가 다시 떴어요

- 처음 한 번만 처리하면 됩니다. 이미 허용하셨다면 다시 뜨지 않아야 합니다.
- 다른 구글 계정으로 시트를 열면 그 계정에서도 한 번씩 허용해야 합니다.
