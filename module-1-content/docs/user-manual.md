## 1. 시작하기 전에 준비할 것

아래 항목들을 미리 준비해주세요. 모두 무료입니다.

| 준비물 | 설명 | 비용 |
|--------|------|------|
| 구글 계정 | 구글 시트, Gemini API에 사용 | 무료 |
| Oracle Cloud 계정 | 서버를 무료로 사용하기 위해 필요 | 무료 (신용카드 등록 필요, 과금되지 않음) |
| 워드프레스 블로그 | 글을 자동으로 올릴 블로그 (선택사항) | 본 패키지에 포함 또는 기존 블로그 사용 |
| 도메인 (선택) | 블로그와 n8n에 사용할 주소 | 무료 도메인 사용 가능 |

> **참고**: 워드프레스 블로그가 없어도 괜찮습니다! 글감 생성만 사용하시면 구글 시트에 자동으로 글이 생성됩니다. 워드프레스 포스팅은 선택사항입니다.

## STEP 1: Oracle Cloud 서버 만들기

Oracle Cloud는 평생 무료로 사용할 수 있는 서버를 제공합니다. 신용카드를 등록하지만 무료 범위 내에서는 절대 과금되지 않습니다.

### 1-1. Oracle Cloud 회원가입

1. 아래 주소에 접속합니다:
   - https://cloud.oracle.com

2. **"Sign Up for Free"** 버튼을 클릭합니다.

> [📸 스크린샷: Oracle Cloud 메인 페이지의 Sign Up for Free 버튼 위치]

3. 회원가입 정보를 입력합니다:
   - **Country**: Korea, Republic of
   - **Name**: 본인 이름 (영문)
   - **Email**: 사용하실 이메일
   - **Home Region**: **South Korea (Chuncheon)** 선택 ⚠️ 이것은 나중에 변경할 수 없으니 반드시 Chuncheon을 선택하세요!

> [📸 스크린샷: 회원가입 양식 - Home Region 선택 화면]

4. 이메일 인증을 완료합니다.

5. 비밀번호를 설정합니다.
   - 대문자, 소문자, 숫자, 특수문자 포함 필요

6. 결제 정보를 입력합니다.
   - 신용카드 또는 체크카드를 등록합니다
   - ⚠️ **무료 티어만 사용하면 과금되지 않습니다**
   - 인증을 위해 소액(약 100원)이 결제 후 자동 취소됩니다

> [📸 스크린샷: 결제 정보 입력 화면]

7. 가입이 완료되면 이메일로 안내가 옵니다. (최대 30분 소요)

### 1-2. 서버(인스턴스) 만들기

1. Oracle Cloud에 로그인합니다.

2. 왼쪽 메뉴에서 **"Compute"** → **"Instances"** 를 클릭합니다.

> [📸 스크린샷: Oracle Cloud 대시보드 - Compute > Instances 메뉴 위치]

3. **"Create Instance"** 버튼을 클릭합니다.

4. 아래와 같이 설정합니다:

   **이름**: `blog-automation` (원하는 이름 아무거나 가능)

   **Image and shape** (이미지와 사양):
   - **Image**: "Ubuntu" 선택 → **Ubuntu 22.04** 선택
   - **Shape**: "Ampere" 카테고리 → **VM.Standard.A1.Flex** 선택
     - OCPU: **4**
     - Memory: **24 GB**

> [📸 스크린샷: 인스턴스 생성 - Shape 선택 화면 (Ampere A1 Flex)]

   **Networking** (네트워크):
   - 기본 설정 그대로 사용

   **Add SSH keys** (SSH 키):
   - **"Generate a key pair for me"** 선택
   - **"Save Private Key"** 버튼을 눌러 키 파일(.key)을 다운로드합니다
   - ⚠️ **이 파일은 서버에 접속할 때 필요합니다. 반드시 안전한 곳에 보관하세요!**

> [📸 스크린샷: SSH 키 생성 및 다운로드 화면]

5. **"Create"** 버튼을 클릭합니다.
   - 서버가 만들어지는 데 2~5분 정도 걸립니다.
   - 상태가 **"Running"** 으로 바뀌면 성공입니다!

6. 서버의 **Public IP Address** 를 메모합니다. (예: `150.230.xxx.xxx`)

> [📸 스크린샷: 인스턴스 상세 페이지 - Public IP 위치 표시]

### 1-3. 방화벽 포트 열기

서버에 웹으로 접속할 수 있도록 포트를 열어야 합니다.

1. 인스턴스 상세 페이지에서 **"Subnet"** 링크를 클릭합니다.

> [📸 스크린샷: 인스턴스 상세 - Subnet 링크 위치]

2. **"Security Lists"** 에서 **"Default Security List"** 를 클릭합니다.

3. **"Add Ingress Rules"** 버튼을 클릭하고 아래 규칙을 추가합니다:

   **규칙 1 (HTTP)**:
   - Source CIDR: `0.0.0.0/0`
   - Destination Port Range: `80`

   **규칙 2 (HTTPS)**:
   - Source CIDR: `0.0.0.0/0`
   - Destination Port Range: `443`

> [📸 스크린샷: Ingress Rules 추가 화면]

4. **"Add Ingress Rules"** 를 클릭하여 저장합니다.

## STEP 2: 서버에 프로그램 설치하기

### 2-1. 서버에 접속하기

**Windows 사용자:**

1. "PuTTY" 프로그램을 다운로드합니다:
   - https://putty.org

2. PuTTY를 실행하고:
   - **Host Name**: 서버의 Public IP (STEP 1에서 메모한 주소)
   - **Port**: 22
   - **Connection Type**: SSH

> [📸 스크린샷: PuTTY 설정 화면]

3. 왼쪽 메뉴에서 **Connection** → **SSH** → **Auth** → **Credentials**:
   - "Private key file for authentication"에서 다운로드한 .key 파일을 선택
   - (PuTTY는 .ppk 형식이 필요합니다. PuTTYgen으로 변환하거나, .key를 직접 사용할 수 있는 경우도 있습니다)

> [📸 스크린샷: PuTTY SSH 키 설정 화면]

4. **Open** 을 클릭하고 로그인 이름에 `ubuntu` 를 입력합니다.

**Mac 사용자:**

1. "터미널" 앱을 엽니다. (Spotlight에서 "터미널" 검색)

2. 아래 명령어를 입력합니다 (경로와 IP는 본인 것으로 변경):
```
chmod 400 ~/Downloads/ssh-key-*.key
ssh -i ~/Downloads/ssh-key-*.key ubuntu@서버IP주소
```

> [📸 스크린샷: Mac 터미널에서 SSH 접속 화면]

3. "Are you sure you want to continue connecting?" 이 나오면 `yes` 를 입력합니다.

### 2-2. 프로그램 설치하기

서버에 접속한 후, 아래 명령어를 **한 줄씩** 복사해서 붙여넣고 Enter를 누릅니다.

**명령어 1: 파일 다운로드**
```
git clone https://github.com/여기에-저장소-주소 blog-automation && cd blog-automation/infrastructure
```

> ⚠️ 위 주소는 구매 시 안내드리는 주소로 교체해주세요.

**명령어 2: 서버 초기 세팅**
```
chmod +x setup.sh && sudo ./setup.sh
```
- 시스템 업데이트와 Docker 설치가 자동으로 진행됩니다.
- 약 3~5분 정도 소요됩니다.
- "서버 세팅 완료!" 메시지가 나오면 성공입니다.

> [📸 스크린샷: setup.sh 실행 완료 화면]

**명령어 3: 환경 설정 파일 만들기**
```
cp .env.example .env
```

**명령어 4: 설정 파일 편집하기**
```
nano .env
```

아래 항목을 수정합니다 (화살표 키로 이동, 직접 타이핑하여 수정):

```
# n8n 관리자 비밀번호 (원하는 비밀번호로 변경)
N8N_USER=admin
N8N_PASSWORD=여기에_비밀번호_입력

# 도메인 설정 (도메인이 없으면 서버IP를 입력)
N8N_HOST=서버IP주소
WP_HOST=서버IP주소

# 워드프레스 DB 비밀번호 (원하는 비밀번호로 변경)
WP_DB_PASSWORD=여기에_DB비밀번호_입력
MYSQL_ROOT_PASSWORD=여기에_ROOT비밀번호_입력
```

수정이 끝나면 `Ctrl + X` → `Y` → `Enter` 를 눌러 저장합니다.

> [📸 스크린샷: nano 에디터에서 .env 파일 편집 화면]

**명령어 5: 프로그램 실행하기**
```
docker compose up -d
```

- 처음 실행 시 필요한 파일을 다운로드하므로 3~10분 정도 걸립니다.
- 완료되면 아래와 같은 메시지가 표시됩니다:
```
✔ Container caddy      Started
✔ Container n8n        Started
✔ Container mysql      Started
✔ Container wordpress  Started
```

> [📸 스크린샷: docker compose up -d 실행 완료 화면]

**명령어 6: 정상 작동 확인**
```
docker compose ps
```
- 4개 컨테이너 모두 **"running"** 상태이면 성공입니다.

> [📸 스크린샷: docker compose ps 결과 - 4개 모두 running]

## STEP 3: Gemini AI API 키 발급받기

Gemini는 구글이 만든 AI입니다. 무료로 사용할 수 있습니다.

1. 아래 주소에 접속합니다:
   - https://aistudio.google.com/app/apikey

2. 구글 계정으로 로그인합니다.

3. **"Create API Key"** 버튼을 클릭합니다.

> [📸 스크린샷: Google AI Studio - Create API Key 버튼]

4. 프로젝트를 선택하는 화면이 나오면 **"Create API key in new project"** 를 클릭합니다.

5. 생성된 API 키를 **복사** 합니다. (예: `AIzaSy...`)
   - ⚠️ **이 키는 비밀번호와 같습니다. 다른 사람에게 공유하지 마세요!**

> [📸 스크린샷: API 키 생성 완료 - 복사 버튼 표시]

6. 이 키를 메모장 등에 임시로 저장해두세요. 다음 단계에서 사용합니다.

## STEP 4: n8n 접속 및 초기 설정

n8n은 자동화 워크플로우를 관리하는 프로그램입니다.

1. 웹 브라우저에서 아래 주소로 접속합니다:
   - `http://서버IP주소:5678`
   - (도메인을 설정한 경우: `https://설정한도메인`)

2. STEP 2에서 설정한 아이디와 비밀번호로 로그인합니다.

> [📸 스크린샷: n8n 로그인 화면]

3. 첫 접속 시 초기 설정 화면이 나옵니다:
   - 이름과 이메일을 입력합니다
   - "Skip" 또는 "Next"를 눌러 진행합니다

> [📸 스크린샷: n8n 초기 설정 화면]

### 4-1. Gemini API 키를 n8n에 등록하기

1. n8n 화면 왼쪽 메뉴에서 ⚙️ **Settings** 를 클릭합니다.

2. **"Variables"** 메뉴를 클릭합니다.

3. 아래 변수들을 추가합니다:

| 변수 이름 | 값 |
|-----------|-----|
| `GEMINI_API_KEY` | STEP 3에서 복사한 API 키 |
| `GOOGLE_SHEET_URL` | STEP 5에서 복사할 구글 시트 URL |
| `WP_HOST` | 워드프레스 주소 (예: `blog.yourdomain.com`) |

> [📸 스크린샷: n8n Variables 설정 화면 - 변수 추가]

## STEP 5: 구글 시트 템플릿 복사하기

1. 아래 구글 시트 템플릿 링크에 접속합니다:
   - (구매 시 안내드리는 링크)

2. **"파일"** → **"사본 만들기"** 를 클릭합니다.

> [📸 스크린샷: 구글 시트 - 사본 만들기 메뉴]

3. 내 구글 드라이브에 복사된 시트가 열립니다.

4. 시트의 컬럼 구조는 아래와 같습니다:

| A열: 키워드 | B열: 상태 | C열: 자동포스팅 | D열: 이미지생성 | E열: 이미지스타일 | F열: 프롬프트(선택) | G열: 생성된 제목 | H열: 생성된 본문 | I열: 포스팅 여부 |
|------------|----------|---------------|---------------|-----------------|-------------------|----------------|----------------|----------------|

**각 컬럼 설명:**
- **키워드**: AI에게 글을 쓸 주제 (예: "겨울 제주도 여행 코스")
- **상태**: `대기` 로 입력하면 자동으로 처리 시작
- **자동포스팅**: `Y` = 워드프레스에 자동 올림 / `N` = 시트에 글만 생성
- **이미지생성**: `Y` = AI가 이미지도 생성 / `없음` = 글만 생성
- **이미지스타일**: `일러스트` / `사진풍` / `미니멀` 중 선택
- **프롬프트(선택)**: 비워두면 기본 프롬프트 사용. 직접 프롬프트를 입력할 수도 있음
- **나머지 컬럼**: 자동으로 채워집니다 (직접 입력하지 마세요)

5. 시트 주소(URL)를 복사합니다.
   - 브라우저 주소창에서 전체 주소를 복사합니다

6. STEP 4에서 n8n Variables에 `GOOGLE_SHEET_URL` 값으로 붙여넣습니다.

## STEP 6: n8n에 워크플로우 가져오기

1. n8n 메인 화면에서 오른쪽 상단의 **"⋮"** (더보기) 메뉴를 클릭합니다.

2. **"Import from File"** 을 클릭합니다.

> [📸 스크린샷: n8n - Import from File 메뉴 위치]

3. 구매 시 받은 파일 중 `content-generator.json` 파일을 선택합니다.

4. 워크플로우가 화면에 나타납니다. 아래와 같은 노드들이 보여야 합니다:
   - Google Sheets 트리거
   - Gemini API 호출
   - 응답 파싱
   - 이미지 생성 여부 확인
   - Imagen API 호출
   - WordPress 포스팅
   - 시트 업데이트

> [📸 스크린샷: 워크플로우 import 완료 후 전체 노드 화면]

## STEP 7: 워크플로우 설정하기

### 7-1. Google Sheets 연결하기

1. **"Google Sheets 트리거"** 노드를 더블클릭합니다.

2. **"Credential to connect with"** 에서 **"Create New Credential"** 을 클릭합니다.

> [📸 스크린샷: Google Sheets 노드 - Create New Credential]

3. 구글 계정 로그인 화면이 나옵니다. 구글 시트가 있는 계정으로 로그인합니다.

4. **"허용"** 또는 **"Allow"** 를 클릭하여 n8n이 구글 시트에 접근할 수 있도록 허용합니다.

> [📸 스크린샷: 구글 OAuth 동의 화면]

5. 연결이 완료되면 노드 설정에서:
   - **Document**: STEP 5의 구글 시트를 선택합니다
   - **Sheet**: "Sheet1" 을 선택합니다

6. **"Save"** 를 클릭합니다.

> ⚠️ 시트 업데이트 노드들(시트 업데이트 (포스팅 완료), 시트 업데이트 (글만 생성) 등)에도 동일한 Google Sheets 인증 정보를 설정해주세요.

### 7-2. Gemini API 확인

1. **"Gemini API 호출"** 노드를 더블클릭합니다.

2. URL에 `{{ $env.GEMINI_API_KEY }}` 가 포함되어 있는지 확인합니다.
   - STEP 4에서 Variables에 API 키를 등록했으므로 자동으로 적용됩니다.

3. 별도 수정 없이 **"Save"** 를 클릭합니다.

## STEP 8: 워드프레스 연결하기

> **자동 포스팅을 사용하지 않으실 분은 이 단계를 건너뛰세요.** 구글 시트에 글만 생성하는 것으로 충분하다면 STEP 9로 바로 이동하세요.

### 8-1. 워드프레스 Application Password 발급

워드프레스에 외부에서 글을 올리려면 전용 비밀번호가 필요합니다.

1. 워드프레스 관리자 페이지에 접속합니다.
   - `http://서버IP주소/wp-admin` (또는 기존 워드프레스 주소)

2. 왼쪽 메뉴에서 **"사용자"** → **"프로필"** 을 클릭합니다.

3. 페이지 아래쪽의 **"Application Passwords"** 섹션을 찾습니다.

4. **"New Application Password Name"** 에 `n8n` 을 입력합니다.

5. **"Add New Application Password"** 를 클릭합니다.

6. 생성된 비밀번호를 **복사**합니다. (예: `xxxx xxxx xxxx xxxx xxxx xxxx`)
   - ⚠️ **이 비밀번호는 한 번만 표시됩니다! 반드시 복사해두세요.**

> [📸 스크린샷: 워드프레스 Application Password 생성 화면]

### 8-2. n8n에 워드프레스 인증 정보 등록

1. n8n에서 워크플로우의 **"WordPress 포스팅"** 노드를 더블클릭합니다.

2. **"Credential to connect with"** 에서 **"Create New Credential"** 을 클릭합니다.

3. **"HTTP Basic Auth"** 를 선택하고:
   - **User**: 워드프레스 관리자 아이디
   - **Password**: 방금 복사한 Application Password

> [📸 스크린샷: n8n HTTP Basic Auth 설정 화면]

4. **"Save"** 를 클릭합니다.

> ⚠️ 이미지 관련 노드(WordPress 이미지 업로드, WordPress 포스팅 (이미지 없음))에도 동일한 인증 정보를 설정해주세요.

## STEP 9: 첫 번째 글 자동 생성 테스트

모든 설정이 완료되었습니다! 이제 테스트해봅시다.

### 9-1. 워크플로우 활성화

1. n8n 워크플로우 화면에서 오른쪽 상단의 **"Active"** 토글을 켭니다.

> [📸 스크린샷: 워크플로우 Active 토글 ON 상태]

### 9-2. 구글 시트에 첫 키워드 입력

1. STEP 5에서 복사한 구글 시트를 엽니다.

2. 첫 번째 행에 아래와 같이 입력합니다:

| 키워드 | 상태 | 자동포스팅 | 이미지생성 | 이미지스타일 |
|--------|------|-----------|-----------|------------|
| 겨울 제주도 여행 코스 | 대기 | N | 없음 | |

> 💡 **첫 테스트에서는 자동포스팅=N, 이미지생성=없음으로 설정하세요.** 글이 정상적으로 생성되는지 먼저 확인한 후에 기능을 하나씩 켜보는 것이 안전합니다.

> [📸 스크린샷: 구글 시트에 테스트 키워드 입력한 모습]

### 9-3. 결과 확인하기

1. 약 5~10분 후 구글 시트를 확인합니다.

2. 아래 컬럼이 자동으로 채워져 있으면 성공입니다!
   - **상태**: `글 생성 완료`
   - **생성된 제목**: AI가 만든 제목
   - **생성된 본문**: AI가 작성한 블로그 글

> [📸 스크린샷: 글 생성 완료된 구글 시트 화면]

### 9-4. 단계별 기능 테스트

글 생성이 성공했다면, 기능을 하나씩 추가해서 테스트합니다:

**테스트 2: 이미지 생성**

| 키워드 | 상태 | 자동포스팅 | 이미지생성 | 이미지스타일 |
|--------|------|-----------|-----------|------------|
| 봄맞이 인테리어 꿀팁 | 대기 | N | Y | 일러스트 |

**테스트 3: 자동 포스팅 (워드프레스 설정 완료 시)**

| 키워드 | 상태 | 자동포스팅 | 이미지생성 | 이미지스타일 |
|--------|------|-----------|-----------|------------|
| 초보자 주식 투자 방법 | 대기 | Y | Y | 사진풍 |

- 워드프레스 관리자 페이지 → "글" 목록에서 초안(Draft) 상태로 올라간 글을 확인할 수 있습니다.

> [📸 스크린샷: 워드프레스 글 목록에 자동 포스팅된 초안 글]

## 일상적인 사용법

설정이 완료된 후에는 매우 간단합니다:

### 글 생성하기
1. 구글 시트를 엽니다.
2. 새로운 행에 키워드와 옵션을 입력합니다.
3. **상태** 컬럼에 `대기` 를 입력합니다.
4. 5~10분 후 결과를 확인합니다.

### 여러 글 한번에 생성하기
여러 행에 키워드를 입력하고 모두 상태를 `대기` 로 설정하면, 순서대로 자동 처리됩니다.

| 키워드 | 상태 | 자동포스팅 | 이미지생성 | 이미지스타일 |
|--------|------|-----------|-----------|------------|
| 다이어트 식단 추천 | 대기 | N | Y | 일러스트 |
| 재택근무 생산성 높이기 | 대기 | Y | Y | 미니멀 |
| 강아지 산책 주의사항 | 대기 | Y | Y | 사진풍 |

### 이미지 스타일 가이드

| 스타일 | 특징 | 추천 주제 |
|--------|------|----------|
| 일러스트 | 깔끔하고 현대적인 디지털 아트 | 가이드, 방법론, 리뷰 |
| 사진풍 | 실제 사진처럼 사실적인 이미지 | 여행, 음식, 인테리어 |
| 미니멀 | 심플하고 깔끔한 디자인 | IT, 비즈니스, 자기계발 |

### 서버 관리
- 서버는 24시간 자동으로 돌아가므로 특별한 관리가 필요 없습니다.
- 서버 상태 확인이 필요하면 SSH로 접속 후:
```
cd blog-automation/infrastructure
docker compose ps
```

## 문제 해결

### "글이 생성되지 않아요"

1. **n8n이 실행 중인지 확인**
   - 브라우저에서 `http://서버IP:5678` 접속이 되는지 확인
   - 안 되면 서버에 SSH로 접속 후: `docker compose restart`

2. **워크플로우가 활성화되어 있는지 확인**
   - n8n에서 워크플로우 Active 토글이 켜져 있는지 확인

3. **구글 시트 상태 컬럼 확인**
   - "대기" 로 정확히 입력했는지 확인 (앞뒤 공백 주의)

4. **n8n 실행 기록 확인**
   - 워크플로우 → "Executions" 탭에서 에러 메시지를 확인

> [📸 스크린샷: n8n Executions 탭 - 실행 기록 확인 방법]

### "이미지가 생성되지 않아요"

1. Gemini API 키가 Imagen API도 지원하는지 확인
2. 이미지생성 컬럼이 `Y` (대문자)로 되어 있는지 확인
3. n8n Executions에서 Imagen API 호출 노드의 에러 메시지를 확인

### "워드프레스에 글이 올라가지 않아요"

1. Application Password가 올바른지 확인
2. 워드프레스 주소가 n8n Variables의 `WP_HOST`와 일치하는지 확인
3. 자동포스팅 컬럼이 `Y` (대문자)로 되어 있는지 확인

### "서버가 갑자기 안 돼요"

1. Oracle Cloud 콘솔에서 인스턴스 상태를 확인합니다.
2. "Stopped" 상태라면 "Start" 버튼으로 다시 시작합니다.
3. SSH 접속 후: `cd blog-automation/infrastructure && docker compose up -d`
